# Runbooks

Procedimientos repetibles para operaciones delicadas: migraciones, backups,
restauraciones, diagnostico de entornos, despliegues y recuperaciones.

Cada runbook debe declarar prerrequisitos, riesgos, pasos, validacion final y
forma segura de retroceder. No debe contener credenciales reales.

Usar la plantilla [Runbook](../PLANTILLAS/RUNBOOK.md).
