# Troubleshooting

Registro de errores complejos o costosos de resolver. El objetivo no es reunir
mensajes de error aislados, sino conservar sintomas, causa raiz, intentos,
solucion comprobada y medidas de prevencion.

Antes de iniciar una investigacion nueva, buscar aqui por sintoma, componente y
entorno. Si el problema no esta registrado, resolverlo con evidencia y crear el
documento al finalizar.

Usar la plantilla [Error resuelto](../PLANTILLAS/ERROR_RESUELTO.md).
